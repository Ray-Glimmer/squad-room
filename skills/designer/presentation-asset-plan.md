# Presentation Asset Plan

## Use

Translate the team's idea into visible pitch or demo assets.

## Inputs

- Current direction
- Demo story
- Risks and judge questions

## Method

1. Give each slide or screen one claim.
2. Pair every claim with one visible artifact.
3. Prefer editable diagrams, tables, and screenshots over decorative visuals.
4. Check whether the audience can understand the story without narration.

## Output

- Slide or screen sequence
- Claim per page
- Asset needed
- Visual QA note

## QA Gate

If the artifact disappeared, the claim should feel weaker; otherwise the visual is decorative.
