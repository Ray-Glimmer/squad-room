# Prototype Spec

## Use

Convert a promising idea into an inspectable prototype plan.

## Inputs

- Chosen direction
- Constraints
- Required demo or deliverable

## Method

1. Define the smallest working loop.
2. List required inputs, outputs, and visible states.
3. Separate manual steps from automated steps.
4. Add a QA check for each risky dependency.

## Output

- Prototype loop
- Required data or assets
- Build sequence
- QA checklist

## QA Gate

The prototype should prove one claim, not the whole roadmap.
