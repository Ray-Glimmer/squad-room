# Quality Gate

## Use

Decide whether the team's current output is ready to move forward.

## Inputs

- Current brief
- Tool artifacts
- Research notes
- User constraints

## Method

1. Identify the highest-risk unsupported claim.
2. Check whether the next artifact actually reduces that risk.
3. Separate blocking issues from polish issues.
4. Ask for a validation artifact when confidence is too low.

## Output

- Pass, watch, or block
- Reason
- Evidence needed
- Next correction

## QA Gate

The critique should make the plan easier to execute, not just harder to defend.
