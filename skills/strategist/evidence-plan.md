# Evidence Plan

## Use

Turn strategic claims into evidence tasks.

## Inputs

- Target user
- Value proposition
- Open questions
- Research results

## Method

1. Identify the decision blocked by missing evidence.
2. Define what evidence would confirm, weaken, or invalidate the claim.
3. Compare alternatives with the same criteria.
4. Keep facts separate from team inference.

## Output

- Research question
- Evidence source
- Comparison dimension
- Decision impact

## QA Gate

A useful evidence plan changes what the team will build, explain, or stop doing.
