# Option Portfolio

## Use

Turn loose ideas into a small portfolio of comparable options.

## Inputs

- User goal
- Current direction
- Constraints and judging criteria

## Method

1. Generate 2-3 meaningfully different options.
2. Name the hook, proof artifact, and failure mode for each option.
3. Avoid options that only differ in wording.
4. Recommend the option that is most testable.

## Output

- Option name
- User-facing hook
- Proof artifact
- Keep/drop reason

## QA Gate

Every option should be demonstrable or testable within the user's current constraints.
